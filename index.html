How it works

Five stages, all running on-device at interactive frame rates.

  1. 1

    Capture

    WebRTC streams camera frames to a canvas. The view is mirrored like a real mirror.

  2. 2

    Detect

    MediaPipe PoseLandmarker (WASM + GPU) returns 33 body landmarks per frame.

  3. 3

    Stabilise

    A One Euro filter removes jitter when you are still and adds no lag when you move.

  4. 4

    Fit

    An affine transform maps the garment's shoulder line and torso axis onto yours.

  5. 5

    Render

    The garment is composited with soft shadow and a fade when tracking is lost.

// js/fit.js — the heart of the fit
const sx = (shoulderWidth * size) / garmentSpan;           // scale along shoulders
const sy = (shoulderWidth * torsoRatio * length) / garmentTorso; // stretch along torso
const matrix = [ux*sx, uy*sx,  dirX*sy, dirY*sy,  e, f];       // rotate + scale + shear
ctx.setTransform(...matrix); ctx.drawImage(shirt, 0, 0);

Engineering highlights

Built like a product, not a notebook.

Robust to real use

Hips out of frame? The fitter falls back to anatomical proportions. Tracking lost? The shirt fades out instead of flickering.

Tested core

All geometry is pure functions covered by a Node test-suite: anchor mapping, rotation, mirroring, filter behaviour.

Zero backend

Static files only. Deploys to GitHub Pages, Netlify or any CDN in seconds, scales to unlimited users at no server cost.

Installable & offline shell

PWA manifest and service worker cache the app shell. Add it to your home screen or desktop.

Bring your own garment

Upload a transparent PNG; borders are auto-trimmed and anchors inferred. Fine-tune with the Fit controls.

Accessible UI

Keyboard shortcuts, ARIA live status, focus rings, reduced-motion support and responsive layout down to phones.

Your camera stays yours.

Inference runs locally through WebAssembly and WebGL. There is no backend: frames are never recorded, uploaded or stored. Snapshots are saved only if you press the button, and only to your own device.
